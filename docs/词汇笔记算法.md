# 词汇笔记算法

代码：`shared/core/wordFamily.ts`（纯算法，可在 Node 里直接跑）、`shared/core/familyNoteService.ts`（前端服务）、
`apps/study/components/FamilyNotePanel.vue`（界面）。

## 四种笔记

| 类型 | 对应的手写笔记 | 中心 | 分支 | 主要数据 |
|---|---|---|---|---|
| 词根族 root | port = carry、terr 恐惧 | 词根及释义 | 按前缀分（ex- / im- / trans-），只有一个分支时按后缀分 | 词素字段、拼写边界、派生 |
| 同义族 synonym | 贫穷的 poor、著名的 famous、开心 | 中文义项 + 最常用的英文词 | 同词性 | 同义词字段、中文义项、ECDICT 同义组 |
| 话题族 topic | 信息传播、金融、运动与身体、环境 | 话题 | 话题内的语义小组 | 话题字段、同义、释义、派生 |
| 拆解图 decompose | atmosphere 思维导图 | 单词 | 词素 → 同词素的词 → 这些词的其他词素 → … | 词素字段、内置词素释义 |

## 数据处理

0. **同名词条合并**：信息最多的一条为主，缺的字段从其他条补。
1. **屈折与拼写变体不单列**：exports 并到 export，rumour 并到 rumor。
2. **词素归一**（前缀、词根、后缀分开命名，后缀键形如 `-ible`）：
   - `MORPHEME_VARIANTS` 合并 port / portat、pos / posit / pon 等变体；
   - 一个形式是另一个的前缀且释义一致时，自动合并（terr / terri / terror）。
3. **同形异义拆分**：释义分属明确不同的概念组时才拆开，例如 terr（恐惧）和 terr（土地）。认不出概念时宁可不拆。
4. **派生识别**：
   - 60 余条后缀还原规则，并处理双写、y 变 i；
   - 基词短于 5 个字母时，要求中文释义有重合，避免 rumor 被认成 rum 的派生；
   - 前缀派生（mis-represent）词义已变，只作为「基词」链接，不并进词族。
5. **拼写边界**：词里含 port 只有在「前缀链 + port + 后缀链」结构时才算（report、export 算，sport、passport、portrait 不算）。拼写像但词根记录不同的，进「易混」。
6. **同义扩展**：
   - 一跳同义；
   - 两跳需要至少两条路径支持；
   - 中文义项按 IDF 加权，太泛的义项（占词库一成以上）不算；
   - 一跳同义词的义项打六折计入；
   - 最后按词性过滤，同一词族只留一个代表。
7. **话题多级**（`splitTopic`）：
   - L1 大类（`topicTaxonomy.ts`）
   - L2 话题（词条自带）
   - L3 主题：相近的语义小组按释义字分布的相似度再聚一次，名称取前三个小组名
   - L4 语义小组：同义、派生、释义词条、释义字重合构成加权图，做标签传播；超过 16 词的只用强关系再切一次；零散词按释义挂到最像的小组，挂不上的按词性归堆
   - L5 词族
   - 组名取组内至少两个词共有、且出现在主义项里的词条
8. **证据与置信度**：每个词都带证据列表。低于 0.7 的默认隐藏，点「待确认」显示。
9. **AI 校对**：
   - AI 只做三件事：删掉不属于这一组的词、补充漏掉的常用词（最多 6 个）、给难词补拆解公式；
   - AI 补进来但词库里没有的词标「补」；
   - AI 不改已有释义。

## 外部数据（可选，强烈建议）

把 ECDICT（MIT 许可，https://github.com/skywind3000/ECDICT）里的 `resemble.txt` 和 `wordroot.txt`
放到资源目录的 `ecdict/` 子目录下（与 `word_explanations` 同级），重启后自动加载：

- `resemble.txt`：同义辨析分组，直接增强同义族；
- `wordroot.txt`：词根表，词库里词素字段缺失的词也能进词根族。

MorphyNet（CC BY-SA 3.0）、MorphoLex（CC BY-NC-SA 4.0，非商业）也可以作为派生关系来源，许可证不同，引入前要确认用途。

## 诊断

先启动 LanguageBridge，然后：

```
npm run family:check -- --coverage
npm run family:check -- terrible export impoverished atmosphere
npm run family:check -- --topic 信息传播
```

输出每种笔记找到了哪些词、凭什么证据，以及词素、同义、话题等字段的覆盖率。笔记质量主要取决于覆盖率。

`npm run test:family` 用 `tests/fixtures/familyLib.ts` 里的模拟词库回归。
