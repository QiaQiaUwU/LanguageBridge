# LanguageBridge 界面规范

改任何界面前先读这份，交付前跑 `npm run check`（模板结构 + 界面规范）。

## 一、样式只用 token

`src/styles/tokens.css` 分三层：调色板 `--r-*`（由主题皮肤写入）、语义 `--c-*`、尺寸与动效（`--space-*`、`--radius-*`、`--text-*`、`--z-*`、`--dur-*`）。
页面样式只用语义层和尺寸层，不写死色值，不直接用 `--r-*`。写死色值有基线（`scripts/lint-ui-baseline.json`），只许减不许增。

## 二、同一种结构只有一种写法

| 结构 | 用什么 |
|---|---|
| 返回 | `<BackLink label="主页" to="/home" />` 或 `@back` |
| 折叠 | `<FoldToggle v-model:folded="x" side="left/right/down" />` |
| 收藏 | `<StarToggle v-model="x" />` |
| 书签 | `<BookmarkToggle v-model="x" />` |
| 已学完 | `<DoneToggle v-model="x" />` |
| 关闭 | `<CloseButton @click="..." />` |
| 空状态 | `<EmptyState />`（默认「暂无」） |
| 搜索框 | `<SearchBox v-model="q" />` |
| 弹窗 | `<UiDialog :open title @close>` |
| 翻页箭头 | `<button class="ui-icon-btn"><i class="ri-arrow-left-s-line"></i></button>` |
| 按钮 | `.ghost-btn`（`.small` `.primary` `.danger`）、`.start-btn` |
| 分段切换 | `.seg > button.on` |
| 标签 | `.chip`（`.on`） |
| 转圈 | `.ui-spin` |
| 右下角通知 | `toast()`（`shared/core/toast.ts`），不自己画 |
| 后台任务 | `runTask()` 或 `startTask/finishTask`，结束必须收尾 |

以上组件已全局注册，页面里直接用。各页面不要再定义 `.ghost-btn`、`.chip`、`.empty-hint`、`.seg-btn`、`.mode-btn`、`.start-btn`。

## 三、可管理列表

用 `shared/core/useManageList.ts`：
- 平时点击即打开；
- 长按或右键进入编辑，条目轻微抖动，显示 ✎ 编辑、× 删除或移出、拖动排序、末尾 ＋；
- 点列表外或「完成」退出。

不在 `<button>` 上用原生 `draggable`。重命名统一叫「编辑」。

## 四、文案

- 界面不写解释、备注、操作指引。
- 按钮用名词或两字动作词，添加入口只用 ＋，名称写进 `title`。
- 搜索框占位只写「搜索」，空状态写「暂无」，错误写状态词（「未关联音频」「未配置 API Key」），不写「请先」「先…再」。
- 确认框只问一句：「移出《…》？」。
- 占位符只写名词（「名称」「标题」「模型」），不写「比如…」「留空则…」「（可选）」。
- 下拉选项、复选框文字不带括号补充：「英美拼法互认」，不写「英美拼法互认（colour = color）」。
- 说明性文字也不能写进用户数据（笔记、词条）里；状态用 `toast()`。
- 不放含义不明的符号和裸数字：没数据就不显示（不用「—」占位）；计数前加图标，含义写进 `title`。

## 五、一件事一个控件

- 已有语速选择，就不再放「慢放」按钮；已有「下一句」，就不再放「跳过」。快捷键可以保留。
- 同一个数值不要同时给数字框和滑条；同一个页面、弹窗不要两个按钮去同一处。
- 设置页不放「去某页调整」这类跳转；那个页面自己有入口就够了。
- 低频、一次性的设置（定时提醒这类）交给 Agent，不占设置页。撤掉界面入口时，Agent 必须能查看、修改、删除已有数据。

## 六、同级选项条

词库、分类这类同级选项排成**一行横向滚动**，不折成两排：
- 滚轮竖向滚动时转成横向；滚到头就把滚轮还给页面；
- 鼠标按住拖动，移动超过 5px 才算拖动，拖动结束那一下的点击要吞掉；触屏走原生滑动；
- 还有内容的一侧渐隐（mask），切换选中项时滚到可见；
- 悬停出现 ✎ × 的卡片要给图标留位，名称过长时截断，全名放进 `title`。

搜索框放在整页最上面。

## 七、数字对得上

- 同一个词表在各页显示的词数必须一致，一律用 `wordStore.groupSize(g)`（只数还存在的词），不直接用 `wordIds.length`。
- 名称不能暗示不成立的关系：只是一部分的词库，不能叫「……（全部）」。
- 列表里没有值就留空；只有表格的空单元格可以用「—」。
- 改了分类或派生算法，交付前跑 `npm run family:check -- --topic <话题>` 抽查一个话题，并跑 `npm run test:family-regress`。

## 八、检查

`npm run check` = 模板结构检查 + `lint:ui`。`lint:ui` 报错的规则：返回 / 关闭 / 收藏 / 折叠的写法、搜索占位、「请先」类提示、
**说明文字**（desc/hint/tip/help/note/sub/intro/caption/cost 类元素里 12 个汉字以上的静态文字，插值里的字符串也算）、
**操作指引**（点一下、再点、可以在、会自动、建议用）、**长占位符**、**「+ 名称」按钮**。写死色值有基线，只许减少。

lint 只能抓到写法固定的问题，交付前仍要人工把改过的页面文案过一遍。
