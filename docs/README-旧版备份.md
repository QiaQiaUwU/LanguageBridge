# LanguageBridge

本地运行的英语学习工具。词库、打字练习、3D 词汇关系图、阅读助手、场景学习都在一个应用里，
数据全部存在自己电脑上，不联网也能用（AI 补全那一步除外）。

## 跑起来

需要 Node.js 18 以上。

**Windows 最省事**：双击 `LanguageBridge.vbs`。首次运行会在桌面建一个图标，
之后从桌面点就行，不弹命令行窗口。

**命令行**：

```bash
node scripts/server.mjs
```

首次启动会自动装依赖并构建，之后只在源码真的变过时才重新构建。
浏览器会自己打开 `http://127.0.0.1:58712`。

已经在跑的时候再点一次启动器，不会开出第二个服务，而是直接把浏览器指到已有的那个。
端口被别的程序占了会自动往上找一个空的，并把新端口写回 `port.txt`。

### 打包成 exe 发给别人

双击 `一键打包EXE.bat`，全程不用输命令。产物在 `dist-exe\`：

```
LanguageBridge.exe            主程序
resources\                    词库（打包时从项目拷进去）
data\                         学习数据
port.txt                      端口
双击打开 LanguageBridge.vbs    启动器
```

整个文件夹拷给别人即可，对方不用装 Node。词库放在 exe 旁边而不是塞进 exe，
因为 pkg 打进去的是只读快照，而 AI 补全、收生词、改标签都要往词库里写。

## 数据放在哪

刚 clone 下来是空的——`data/` 和 `resources/` 都不进仓库（见 `.gitignore`），
它们是使用者自己的资料。

| 目录 | 装什么 | 能不能删 |
| --- | --- | --- |
| `resources/word_explanations/` | 词库原本，一个词一个 JSON | **不能**，这是原始资料 |
| `resources/articles/` | 阅读助手的文章，一篇一个 JSON | 不能 |
| `resources/word_index.json` | 分类索引，从词库扫出来的 | 能，设置页一键重建 |
| `data/words.json` | 工作缓存，为了启动读一个文件而不是一万五千个 | 能，设置页一键从词库重建 |
| `data/` 下其余文件 | 学习状态：词表、记忆卡片、活动日志、设置 | 不能，删了学习进度就没了 |

一句话：**`resources/` 是原本，`data/words.json` 是可再生的缓存，`data/` 下其余是学习记录。**

## 主要模块

- **词汇中心** — 词库浏览与筛选。考试 / 话题 / 词根词缀三个维度并行叠加，
  再叠一层认识 / 模糊 / 不认识。
- **词汇宇宙** — 3D 力导向关系图。同根词、近义词、反义词、词形变换四类关系，
  核心词做恒星、衍生词做卫星缓慢公转。按掌握程度上色时亮度来自记忆曲线，
  学熟了亮、长期不复习自己暗下去。
- **学习 / 打字** — 判定逻辑对照 [TypeWords](https://github.com/zyronon/typing-word) 实现：
  逐字符实时判定、默写模式统一校验、跟写 / 拼写 / 听写 / 自测多种练习类型。
  复习排期用 FSRS。
- **阅读助手** — 导入文章，逐句对照、划词入库、朗读、复述批改。
- **听写检测** — 听发音写单词。单词模式一个一个来，列表模式一屏铺开、填完统一判分。
  错词循环、连胜统计、错词本闭环（答对自动移出，反复听到全对）。
- **单词测试** — 给中文选英文的四选一测卷。干扰项优先取同词族变体和近义词，
  随机干扰项一眼就能排除、题等于白出。
- **场景学习** — 按话题生成成套教材与实战批改。

## 影子跟读

阅读助手里可以给文章配音频，然后一句句跟读。三条路拿到"每句从第几秒到第几秒"：

1. **导入字幕**（`.srt` / `.vtt`）— 最准最快，视频自带字幕时首选
2. **拖入视频** — 本机 `ffmpeg` 抽出音轨，原视频不保存（需要自己装 ffmpeg 并加进 PATH）
3. **自动转写** — 本机跑 whisper，音频不出这台电脑（需要 whisper.cpp 或 openai-whisper）

对轴之后跟读面板可以连续播放：读到哪句高亮哪句、自动滚动，可调速度、单句循环、
句间停顿（「跟句子等长」那一档正好留出照着念一遍的时间）。

## 备份

设置页「整体备份」导出一个文件，含词条、词表、记忆卡片、错词本、已掌握、
学习设置、配色覆盖。换电脑或重装浏览器之后「恢复备份」读回来。

浏览器里那份数据只是缓存，`resources/` 和 `data/` 才是原本 —— 阅读助手里
「从后端恢复」可以在浏览器数据被清掉之后把文章拉回来。

## AI 补全

词库原本里没有话题和词根词缀这两项，需要模型补一次。设置页「AI 补全」，
用的是右下角 AI 面板里配好的连接（key 存在浏览器本地，不进仓库也不上传）。

跑法是先扫一遍看每个词缺什么，按"缺的是同一组东西"归堆再切批，
所以提示词只问这批真缺的项；每批立刻落盘，中断了下次从断点接着走。
考纲标签不问模型——词库 JSON 里本来就有，设置页有免费的回填。

## 开发

```bash
npm run check    # 模板结构自检：标签配对、v-if 链完整性
npm run build    # 自检通过才构建
```

`npm run build` 前置了模板检查，是因为批量编辑很容易把 `v-else` 链打断或者
删掉正在被调用的函数，而这类错只在构建时才暴露。
